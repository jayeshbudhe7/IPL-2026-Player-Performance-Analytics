# IPL 2026 Player Performance Analytics

## Project Overview
This project analyzes IPL 2026 player performance using MySQL, Python (Pandas), and Power BI. It focuses on batting, bowling, fielding, and team-wise performance.

## Project Objectives
- Identify the top 10 run scorers.
- Analyze the top 10 wicket takers.
- Identify players with the most sixes and fours.
- Compare team-wise and role-wise performance.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- MySQL Workbench – Data storage and SQL analysis
- Python – Data analysis using Pandas
- Power BI – Interactive dashboard and visualization
- CSV – Dataset format
- VS Code – Python coding and documentation

## Dataset
- File: IPL_2026_Stats.csv
- Records: 100 players
- Columns: 13
- Includes player name, team, role, matches, runs, fours, sixes, dots, catches, extras, wickets, LBW, and season.

## Project Structure
- Dataset – IPL dataset
- MySQL – SQL analysis files
- Python – Python analysis code
- PowerBI – Power BI dashboard
- Project_Report – Project documentation
