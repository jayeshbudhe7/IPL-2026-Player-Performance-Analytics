Project Overview

This project explores IPL 2026 player statistics, including runs, wickets, fours, sixes, catches and team-wise performance.

MySQL

SQL queries and player performance analysis.

Python

Data analysis and data inspection using Pandas.

Power BI

Interactive dashboard with charts and filters.
